## ✨ What Makes RMV Master Academy Special?

RMV Master Academy isn't just another set of flashcards—it's a complete, intelligent study system tailored specifically to the **April 2026 MassDOT Driver's Manual** and **Massachusetts General Laws Chapter 90 (M.G.L. c. 90)**.

### 🌟 Key Features

* ⏱️ **Official 25-Question Kiosk Simulator**: Take realistic, timed 25-minute practice exams matching the exact 72% passing threshold (18/25 correct) used at MassDOT RMV test centers.
* 📚 **Interactive 5-Chapter Study Manual**: Clean summaries, core driving principles, speed limits, right-of-way rules, and statutory fee tables simplified for fast reading.
* 🎴 **Chapter Drills & Flashcards**: Flip through high-yield flashcards with instant visual feedback and rationale for every question.
* 🔍 **300+ Question Repository (`⌘K` Command Search)**: Easily search any driving rule, fine, speed limit, or statute in milliseconds with a keyboard-driven command palette.
* 🎯 **Smart "Knowledge Gaps" Remediation**: The app automatically analyzes your past test reports, detects topics you missed, and builds custom practice drills to turn weak spots into strengths.
* 🏆 **Academic Honours & Badges**: Earn 16 visual badges (like *Rotary Maestro*, *JOL Curfew Specialist*, and *Zero Distraction Scholar*) as you build your passing streak and gain XP!
* 📱 **100% Mobile & Laptop Friendly**: Seamlessly responsive design that looks and feels great on phones, tablets, and computers.

## 🚀 Quick Start (Run Locally)

Want to run the app on your own computer or contribute? It takes less than 2 minutes!

```bash
# 1. Clone the repository
git clone https://github.com/aartisr/dmv-question-bank.git

# 2. Navigate into the folder
cd dmv-question-bank

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Open `http://localhost:3000` in your browser and start studying! 🎈
